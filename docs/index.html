All-in-one Linux utility app

FortranOmni is an open-source Linux utility app built with GTK 4 and GJS. It combines Linux system tools, developer tools, file organization, password generation, network tools, timers, and everyday desktop utilities into one application.

Everything in one place.

FortranOmni combines useful everyday Linux utilities into one expandable GTK desktop application.
